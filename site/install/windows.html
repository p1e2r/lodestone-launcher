One-command install

The quickest way, with no SmartScreen warning. Open PowerShell (click Start, type PowerShell, press Enter), paste this and press Enter:

iex ((New-Object Net.WebClient).DownloadString('https://p1e2r.github.io/lodestone-launcher/install.ps1'))

It downloads the latest installer, installs Lodestone for your user and opens it. Run it again any time to reinstall.

Install

Prefer to click through it yourself? Use the installer:

  1. Download the installer

    Download Lodestone-windows-x64-setup.exe. If Edge says the file “isn't commonly downloaded”, click … → Keep → Show more → Keep anyway. In Chrome, click Keep.

  2. Open it and get past SmartScreen

    Lodestone isn't code-signed yet, so Windows may show “Windows protected your PC”. Click More info, then Run anyway. You only need to do this once.

  3. Run the installer

    Tick Create a desktop shortcut if you want one, then click Install. Lodestone goes into %LOCALAPPDATA%\Programs\Lodestone, so there's no admin prompt. Leave Launch Lodestone ticked and click Finish.

  4. Play

    Click your name at the bottom of the sidebar (or open Accounts) and add a username. Then click New instance, pick a Minecraft version and a mod loader, and press Play. The first launch of each version downloads the game and the right Java, a few hundred MB.

Without the installer

Download Lodestone-windows-x64.exe and open it from anywhere, like your Downloads folder. On first launch it copies itself to %LOCALAPPDATA%\Programs\Lodestone, adds a Start Menu entry and an uninstaller, and reopens from there. You can delete the downloaded file afterwards.

Updating

When a new version is out, an Update card appears at the bottom of the sidebar. Click Update and Lodestone downloads it, replaces itself and reopens. You can also check from Settings → Updates. Your instances, worlds and accounts are kept.

Where files go

App
%LOCALAPPDATA%\Programs\Lodestone\Lodestone.exe
Instances, worlds, accounts
%APPDATA%\p1e2r\Lodestone\data

Paste either path into the File Explorer address bar to open it. Each instance also has an Open folder button.

Uninstalling

Open Settings → Apps → Installed apps, find Lodestone, and choose Uninstall. This removes the app but keeps your worlds. To remove everything, also delete %APPDATA%\p1e2r\Lodestone.

Troubleshooting

“Windows protected your PC” appears

Click More info, then Run anyway. The warning appears for apps without a paid code-signing certificate.

My antivirus deleted Lodestone.exe

Some antivirus tools flag new unsigned programs. Restore the file from quarantine and add an exception for %LOCALAPPDATA%\Programs\Lodestone. Every release is built from the public source by GitHub Actions.

Lodestone's window is blank or closes right away

Update your graphics driver from your GPU maker (NVIDIA, AMD or Intel), then open Lodestone again.

Minecraft doesn't start

Open the instance and check the Log tab for the error. If it's a mod crash, turn off the newest mods in the Content tab. Still stuck? Report a bug with the log.
