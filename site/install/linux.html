Install on Linux

Unpack one file, make sure Vulkan is installed, and run it. Optionally add it to your app menu.

Linux · x86_64

A single program in a .tar.gz archive, with its icon.

Download .tar.gz Lodestone-linux-x64.tar.gz

From a terminal

Downloads the latest release into the current folder.

curl -LO https://github.com/p1e2r/lodestone-launcher/releases/latest/download/Lodestone-linux-x64.tar.gz

Install

  1. Download the archive

    Download Lodestone-linux-x64.tar.gz, or use the curl command above.

  2. Unpack it

    This puts Lodestone in ~/.local/opt/lodestone. Run it from the folder you downloaded to:

    mkdir -p ~/.local/opt/lodestone && tar -xzf Lodestone-linux-x64.tar.gz -C ~/.local/opt/lodestone

  3. Install the graphics libraries

    Most desktops already have them. If not, see Graphics libraries for your distribution.

  4. Run it

    ~/.local/opt/lodestone/lodestone

    Click your name at the bottom of the sidebar (or open Accounts) and add a username. Then click New instance, pick a Minecraft version and a mod loader, and press Play. The first launch of each version downloads the game and the right Java, a few hundred MB.

Graphics libraries

Lodestone draws its window with Vulkan and needs the X11 keyboard library.

Ubuntu, Debian, Linux Mint, Pop!_OS

sudo apt install libxkbcommon-x11-0 libxcb1 libvulkan1 mesa-vulkan-drivers

Fedora

sudo dnf install libxkbcommon-x11 vulkan-loader mesa-vulkan-drivers

Arch, Manjaro, EndeavourOS

sudo pacman -S --needed libxkbcommon-x11 vulkan-icd-loader

On Arch, also install the Vulkan driver for your GPU: vulkan-radeon (AMD), vulkan-intel (Intel) or nvidia-utils (NVIDIA). On every distribution, NVIDIA cards need the proprietary driver.

Add to the app menu

Run this once to give Lodestone an entry with its icon in your desktop's app menu:

mkdir -p ~/.local/share/applications cat > ~/.local/share/applications/lodestone.desktop <<EOF [Desktop Entry] Type=Application Name=Lodestone Comment=Minecraft launcher Exec=$HOME/.local/opt/lodestone/lodestone Icon=$HOME/.local/opt/lodestone/lodestone.png Categories=Game; EOF

Updating

When a new version is out, an Update card appears at the bottom of the sidebar. Click Update and Lodestone replaces the file in ~/.local/opt/lodestone and reopens. You can also check from Settings → Updates. Your instances, worlds and accounts are kept.

Where files go

~/.local/opt/lodestone/lodestone

Uninstalling

Remove the app and its menu entry:

rm -rf ~/.local/opt/lodestone ~/.local/share/applications/lodestone.desktop

This keeps your worlds. To remove everything, also delete the data folder:

rm -rf ~/.local/share/lodestone

Troubleshooting

“error while loading shared libraries: libxkbcommon-x11.so.0”

Install the graphics libraries for your distribution.

“version `GLIBC_2.3x' not found”

Your distribution is older than Lodestone supports. It needs glibc 2.35 or newer: Ubuntu 22.04, Debian 12, Fedora 36 or later.

The window doesn't open, or there's a Vulkan error

Install a Vulkan driver for your GPU (see above). To check that Vulkan works, install vulkan-tools and run vulkaninfo --summary.

“Permission denied” when running it

Make it executable: chmod +x ~/.local/opt/lodestone/lodestone.

Minecraft doesn't start

Open the instance and check the Log tab for the error. If it's a mod crash, turn off the newest mods in the Content tab. Still stuck? Report a bug with the log.
