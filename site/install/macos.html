Install on macOS

Run one command and Lodestone installs the right build for your Mac. Or download the arm64 (Apple Silicon) or x86_64 (Intel) disk image yourself.

Apple Silicon · arm64

For Macs with an M1, M2, M3, M4 or newer chip.

Download for Apple Silicon Lodestone-macos-arm64.dmg

Intel · x86_64

For Macs with an Intel processor.

Download for Intel Lodestone-macos-intel.dmg

One-command install

The easiest way. Open Terminal (press ⌘ Space, type Terminal, press Return), paste this and press Return:

curl -fsSL https://p1e2r.github.io/lodestone-launcher/install.sh | sh

It picks the build for your chip (Apple Silicon or Intel), installs Lodestone into Applications and opens it. macOS doesn't block it, because it wasn't downloaded by a browser. Run it again any time to reinstall.

Which Mac do I have?

Open the Apple menu → About This Mac and look at the first line.

“Chip: Apple M1” (or M2, M3, M4…)

You have Apple Silicon. Download the arm64 build.

“Processor: … Intel Core …”

You have an Intel Mac. Download the Intel (x86_64) build.

The Intel build also runs on Apple Silicon through Rosetta 2, but slower. The arm64 build does not run on Intel Macs.

Install from the .dmg

Installing by hand works too, with one Terminal command at the end.

  1. Open the disk image

    Double-click the file you downloaded: Lodestone-macos-arm64.dmg on Apple Silicon or Lodestone-macos-intel.dmg on Intel.

  2. Drag Lodestone to Applications

    In the window that opens, drag the Lodestone icon onto the Applications folder. Then eject the disk image with the ⏏ button next to it in the Finder sidebar.

  3. Allow it to open

    Lodestone isn't notarized by Apple yet, so macOS says it's “damaged” when it comes from a browser. Paste this into Terminal (Applications → Utilities → Terminal) and press Return:

    xattr -dr com.apple.quarantine /Applications/Lodestone.app

    This removes the “downloaded from the internet” flag from Lodestone only. The one-command install above skips this step.

  4. Play

    Open Lodestone from Applications, Launchpad or Spotlight. Click your name at the bottom of the sidebar (or open Accounts) and add a username. Then click New instance, pick a Minecraft version and a mod loader, and press Play. The first launch of each version downloads the game and the right Java, a few hundred MB.

Without admin rights

The one-command install handles this for you: if you can't write to /Applications, it installs into the Applications folder in your home folder instead. By hand, drag Lodestone into Applications inside your home folder (create it if it's missing), then run:

xattr -dr com.apple.quarantine ~/Applications/Lodestone.app

If you open Lodestone from anywhere else, such as Downloads, it moves itself to ~/Applications and reopens, so Spotlight and Launchpad can find it.

Updating

When a new version is out, an Update card appears at the bottom of the sidebar. Click Update and Lodestone installs the new version for the same chip and reopens; there's no need to allow it again. You can also check from Settings → Updates. Your instances, worlds and accounts are kept.

Installed the Intel build on an Apple Silicon Mac by mistake? Download the arm64 build and drag it over the old one. Your data stays.

Where files go

App
/Applications/Lodestone.app or ~/Applications/Lodestone.app
Instances, worlds, accounts
~/Library/Application Support/dev.p1e2r.Lodestone

To open the data folder, press ⇧⌘G in Finder and paste the path. Each instance also has an Open folder button.

Uninstalling

Quit Lodestone and drag it from Applications to the Trash. This keeps your worlds. To remove everything, also delete the data folder:

rm -rf ~/Library/Application\ Support/dev.p1e2r.Lodestone

Troubleshooting

“Lodestone is damaged and can't be opened”

The app isn't damaged: this is how macOS reports a downloaded app that isn't notarized. Use the one-command install, or run the Terminal command from step 3 and open it again.

“Apple could not verify Lodestone is free of malware”

Use the one-command install, or the Terminal command from step 3.

“You can't open the application because it isn't supported on this type of Mac”

You downloaded the arm64 build on an Intel Mac. Get the Intel build instead.

macOS asks to install Rosetta

You're running the Intel build on an Apple Silicon Mac. Install Rosetta, or better, switch to the arm64 build.

“Lodestone requires macOS 12.0 or later”

Lodestone supports macOS 12 Monterey and newer. Update macOS from System Settings → General → Software Update, if your Mac supports it.

Minecraft doesn't start

Open the instance and check the Log tab for the error. If it's a mod crash, turn off the newest mods in the Content tab. Still stuck? Report a bug with the log.
